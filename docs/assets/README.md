# 展示资源（assets）

本目录存放**对外展示**用的图片资源，供 `汉化成果速览.html`、`汉化展示主页.md`、
推广视频素材与 README 引用。

## 内容

| 文件 / 目录 | 说明 |
|---|---|
| `iqmol_bili_cover.png` | 数据卡封面图（与 B 站成片封面一致） |
| `ui/` | **实机运行截图（中文界面）**，详见下表 |

### `ui/` 截图清单

| 类别 | 文件 | 说明 |
|---|---|---|
| 工具栏图标 | `Add.png` `AddFragment.png` `AddHydrogens.png` `Camera.png` `Configure.png` `Display.png` `Film.png` `Help.png` `MagicWand.png` `Manipulate.png` `Minimize.png` `NewDocument.png` `Open.png` `Remove.png` `Save.png` | 界面工具栏图标（中文版） |
| 应用主图标 | `iqmol.png` | 主窗口/快捷方式图标 |
| 对话框 | `dlg_appearance.png` `dlg_camera.png` `dlg_insmol.png` `dlg_jobmonitor.png` `dlg_qchem.png` `dlg_server.png` | 外观 / 相机 / 插入分子 / 任务监视器 / Q-Chem 设置 / 服务器配置 |
| 顶部菜单 | `menu_文件.png` `menu_编辑.png` `menu_显示.png` `menu_构建.png` `menu_计算.png` `menu_帮助.png` | 六大主菜单展开态 |
| 3D 视图 | `view3d_porphyrin.png` | 3D 分子视图示例（卟啉，实机 OpenGL 渲染） |

## 引用方式

- `汉化成果速览.html`（同目录上一级）以**仓库 raw 绝对链接**引用本目录图片，
  以便 GitHub Pages 与本地预览一致，详见该文件顶部切换注释。
- 新增/替换图后，同步检查 `../汉化成果速览.html`、`../汉化展示主页.md` 与
  `../验证记录/` 中的引用路径。
