## 六、重新测量方法

```bash
cd <仓库根>
BASE=af7ff60                    # 或上游最新提交

# 总量
git diff --name-status $BASE HEAD | grep -c '^M'   # 修改
git diff --name-status $BASE HEAD | grep -c '^A'   # 新增
git diff --name-status $BASE HEAD | grep -c '^D'   # 删除

# 含 tr() 的源码文件数
for f in $(git diff --name-only $BASE HEAD | grep -E '\.(C|h)$'); do
  git diff $BASE HEAD -- "$f" | grep -q '^+.*tr(' && echo "$f"
done | wc -l
```

> 待第三层方案 D 项落地后，以上命令应封装为 `scripts/i18n/change_surface.sh`。
