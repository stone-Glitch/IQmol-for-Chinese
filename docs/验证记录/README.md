## 三、复现验证

编译、运行与翻译资产校验的可执行命令见
[`../构建与打包/构建与部署指南.md`](../构建与打包/构建与部署指南.md) 第七章「验证构建结果」，
本文不再重复维护一份（避免两处口径漂移）。

关键判定：启动日志出现 `[i18n] Loaded translation: "zh_CN"` 即中文翻译加载成功
（该日志走 **stderr**，排查时记得 `2>&1`）。
