# Linux 分发包中文翻译加载失败（已实测定位）

**发现日期**：2026-09-24
**影响产物**：`submodules-package/linux-build/IQmol-linux-x86_64.tar.gz`
**严重级别**：**高**（中文界面静默失效，用户看到英文）

---

## 一、现象

在 Linux 预编译包上无头启动 IQmol，程序日志出现：

```
[i18n] No translation file found for: "zh_CN"
```

即**中文翻译未加载，界面回退英文**——尽管翻译文件就在包内。

---

## 二、复现步骤

```bash
tar -xzf IQmol-linux-x86_64.tar.gz
cd IQmol-linux-x86_64/bin
export LD_LIBRARY_PATH=../lib:$LD_LIBRARY_PATH
export QT_QPA_PLATFORM=offscreen
./IQmol --clear-jobs
# 观察输出中的 [i18n] 行
```

预期：`[i18n] Loaded translation: "zh_CN"`
实际：`[i18n] No translation file found for: "zh_CN"`

---

## 三、根因

翻译文件位置与程序搜索路径不匹配。

`src/Main/IQmolApplication.C:114-118` 的搜索路径为：

```cpp
QStringList searchPaths;
searchPaths << QApplication::applicationDirPath() + "/translations"   // bin/translations/
            << QApplication::applicationDirPath()                     // bin/
            << QDir::current().filePath("translations")               // cwd/translations
            << QDir::currentPath();                                   // cwd/
```

`applicationDirPath()` = 可执行文件所在目录 = `bin/`。

而包内实际布局为：

```
IQmol-linux-x86_64/
├── bin/IQmol                  ← applicationDirPath() = .../bin
├── translations/zh_CN.qm      ← 实际位置（在 bin 的上一级）
├── lib/
└── share/
```

**`bin/translations/` 不存在**，且从 `bin/` 启动时 `cwd/translations`
也指向 `bin/translations/`（若用户 `cd bin` 后运行）——两条路径均落空。

> 注：这与 Windows 侧的约定不同。Windows 部署时 `deploy_windows.sh` 会把
> `zh_CN.qm` 复制到 `build/bin/translations/`，与 `applicationDirPath()`
> 一致，因此 Windows 包不受影响。Linux 打包脚本未做同样处置。

---

## 四、验证：修正后即加载成功

```bash
mkdir -p bin/translations
cp translations/zh_CN.qm bin/translations/
cd bin && ./IQmol --clear-jobs
# → [i18n] Loaded translation: "zh_CN"     ✅
```

**根因确认**：仅需把 `.qm` 放到 `bin/translations/`，加载即成功。

---

## 五、修复方案

### 方案 A（推荐）：打包脚本补一步

在 Linux 打包流程中，把 `translations/*.qm` 复制到 `bin/translations/`：

```bash
mkdir -p "$STAGE/bin/translations"
cp "$STAGE"/translations/*.qm "$STAGE/bin/translations/"
# 同时保留包根的 translations/ 以兼容旧布局与 run.sh
```

### 方案 B：源码侧增加搜索路径

在 `loadTranslations()` 的 `searchPaths` 中增加 `../translations`
（即 `applicationDirPath() + "/../translations"`），兼容包根布局：

```cpp
searchPaths << QApplication::applicationDirPath() + "/translations"
            << QApplication::applicationDirPath() + "/../translations"   // 新增
            << QApplication::applicationDirPath()
            ...
```

> **建议两者都做**：A 立即修复产物，B 提升对布局差异的鲁棒性。

---
