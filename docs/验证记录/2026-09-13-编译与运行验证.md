## 五、本轮发现并修复的问题（Windows 构建路径）

以下问题均通过**源码静态推演**提前发现，而非依赖报错回溯：

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | libarchive 调 libiconv 签名冲突 | OpenBabel 自带 `iconv.h` 声明 `const char**`，libarchive 的 `CHECK_ICONV` 在 MinGW 探测失败致 `ICONV_CONST` 为空 | configure 期幂等修补 `archive_string.c`，实参转型 `(const char**)&itp` |
| 2 | QGLViewer/yaml-cpp 报 `__imp_` 未定义 | 静态库但头文件按 DLL 导入展开（缺 `QGLVIEWER_STATIC` / `YAML_CPP_STATIC_DEFINE`） | Windows 下 `add_compile_definitions` 补两个静态宏 |
| 3 | 缺 `__imp_glStencil*` | `find_package(OpenGL)` 在 CMake 3.14+ 不再设置旧变量 `${OPENGL_LIBRARIES}` | 收敛为 `OPENGL_TARGET`（`OpenGL::GL` 优先，Windows 回退 `opengl32`） |
| 4 | 缺 `gluNewQuadric` 等 | 从未链接 GLU 库 | 新增 `GLU_TARGET`（`OpenGL::GLU` / `glu32`） |
| 5 | 缺 `MD5` 等 OpenSSL 符号 | `Network` 以 `PRIVATE` 链 OpenSSL，静态库依赖不传播 | 顶层补 `OpenSSL::SSL` + `OpenSSL::Crypto` |
| 6 | 改配置后不重跑 configure | 脚本仅凭缓存文件存在就跳过 configure | 增加时间戳判定，`CMakeLists.txt` 较新则自动重配 |

## 六、运行期部署要点（Windows）

依据 `src/Main/IQmolApplication.C` 与 `src/Util/Preferences.C` 的运行时查找规则：

| 资源 | Windows 期望路径 | 说明 |
|---|---|---|
| 可执行文件 | `bin/IQmol.exe` | — |
| Qt 插件 | `lib/`、`lib/plugins/` | 源码 `addLibraryPath` 显式指定 |
| 着色器 | `share/shaders/` | 5 个着色器，**不在 .qrc 内**，必须外部提供 |
| 片段库 | `share/fragments/` | — |
| Q-Chem 数据库 | `share/qchem_option.db` | — |
| OpenBabel 数据 | `share/openbabel/` | `BABEL_DATADIR` |
| 中文翻译 | `bin/translations/zh_CN.qm` | POST_BUILD 自动生成 |

> Windows 下代码执行 `applicationDirPath()` → `cdUp()`，故运行时根为 `build/`；
> Linux 下则硬编码 `/usr/share/iqmol/`（本次验证即按此安装资源）。

配套脚本 `scripts/deploy_windows.sh` 已实现上述所有步骤的自动化。

## 附：验证环境复现命令

```bash
# 1. 安装依赖
apt-get install -y gcc g++ cmake make \
  qtbase5-dev qtbase5-dev-tools qttools5-dev qttools5-dev-tools \
  libqt5opengl5-dev libqt5sql5-sqlite libboost-dev libssl-dev zlib1g-dev \
  libglu1-mesa-dev libgl1-mesa-dev libxml2-dev libarchive-dev \
  libssh2-1-dev libopenbabel-dev openbabel

# 2. 解压源码与子模块
tar xzf IQmol-submodules.tar.gz -C IQmol3/

# 3. 配置与编译
mkdir IQmol3/build_linux && cd IQmol3/build_linux
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j24

# 4. 运行（Linux 需资源位于 /usr/share/iqmol）
mkdir -p /usr/share/iqmol && cp -r ../share/* /usr/share/iqmol/
./IQmol
```
