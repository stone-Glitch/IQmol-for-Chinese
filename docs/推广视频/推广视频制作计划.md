### 2.4 决策记录：为何自产录屏

原计划依赖外部提供主界面截图，已改为虚拟显示器实机录屏。取舍如下：

| | 等截图（原） | **自产录屏（现）** |
|---|---|---|
| 依赖 | 阻塞，需等人 | 零依赖，随时可重录 |
| 真实性 | 静态图，说服力弱 | 实机视频，可直接展示旋转 / 菜单 |
| 一致性 | 分辨率 / 版本可能不统一 | 同一环境同一次运行，风格统一 |
| 可迭代 | 改一次要重新找人拍 | 改脚本重跑即可 |

## 三、虚拟窗口录屏方案（已实测验证）

### 3.1 原理

无显卡 / 无物理显示器的环境里，用三层软件栈模拟真实桌面：

```
Xvfb（虚拟 X 显示，1920×1080）
  └─ Mesa llvmpipe（CPU 软件 OpenGL，4.5 Compatibility Profile）
       └─ openbox（窗口管理器 —— 必需，见 3.3 坑 1）
            └─ IQmol（真实二进制，中文界面）
                 └─ ffmpeg x11grab（抓屏录制）
```

### 3.2 验证结果

| 环节 | 结果 |
|---|---|
| Qt5 OpenGL 上下文创建 | ✅ `context_created: true`，`makeCurrent: true` |
| GL 版本 | ✅ 4.5 Compatibility Profile（Mesa 25.2.8 / llvmpipe / LLVM 20.1.2） |
| IQmol 着色器编译 | ✅ Cel / Gooch / Gouraud / Phong / Plastic 5 个全部成功 |
| 中文界面 | ✅ 日志 `[i18n] Loaded translation: "zh_CN"`；菜单栏「文件 编辑 显示 构建 计算 帮助」 |
| 中文渲染（无方块） | ✅ Noto Sans CJK SC / Droid Sans Fallback 均正常 |
| 分子渲染 | ✅ 球棍模型（西地那非）、蛋白二级结构（3nir）均正常 |
| 录屏 | ✅ H.264 / 1920×1080 / 25fps，帧间可见分子旋转 |
| zh_CN locale | ✅ `locale-gen` 后 `date` 输出「2026年 10月 02日 星期五」 |

### 3.3 踩过的坑（已固化进脚本）

| # | 坑 | 现象 | 解法 |
|---|---|---|---|
| 1 | 缺窗口管理器 | 截图里窗口只占屏幕左上角一块，`xdotool windowsize` 无效 | 启动 **openbox**；无 WM 时 Qt 的 resize 请求不被落实 |
| 2 | 误禁 GLX | `Cannot create platform OpenGL context, neither GLX nor EGL are enabled` | **不要**设 `QT_XCB_GL_INTEGRATION=none`；用 `xcb_glx` |
| 3 | 后台进程被回收 | Xvfb 起来又消失，`unable to open display` | Xvfb / openbox 放**独立后台任务**常驻；普通 `&` 会随会话结束被带走 |
| 4 | locale 未生成 | `setlocale: LC_ALL: cannot change locale (zh_CN.UTF-8)` | 先 `locale-gen zh_CN.UTF-8` |
| 5 | 判断中文是否生效靠肉眼 | 界面看着是中文，但不确定 | 认日志 `[i18n] Loaded translation: "zh_CN"`，这是权威标志 |
| 6 | 全量编译中途静默中断 | 日志无错误、无 OOM，突然停在某文件 | 沙箱会话回收所致；重跑 `make` 自动续上（已编译的不重编） |
| 7 | **误以为录到了英文界面** | 4 次录制日志全是 `Loaded translation: "zh_CN"`，却拿它们当「中英对照」，实为中文对中文 | 认日志不认画面（见 2.1 注）；`Language=en` 录完**必须**删掉 QSettings 的 `Language` 键再录中文，否则后续录制沿用英文状态 |

### 3.4 脚本与用法

| 脚本 | 用途 |
|---|---|
| `scripts/video/setup_virtual_display.sh` | 校验依赖 + 生成 zh_CN locale + 打印常驻启动命令 |
| `scripts/video/record_virtual_display.sh` | **主脚本**：启动 IQmol → 等中文加载 → 视图居中 → 录屏 + 鼠标旋转分子 |
| `scripts/video/record_hero_clip.sh` | 主视觉素材录制（hero），可切 `Language=en` 录英文版 |
| `scripts/video/rec_4a.sh` | 段 4 对话框录屏（BuildMol / QUI / Orbital 同款流程） |
| `scripts/video/prepare_assets.sh` | 生成二维码、收尾卡、数据条、钩子 / 痛点段素材 |
| `scripts/video/compose_main.sh` | **主合成**：五段拼接 + 字幕 + BGM 混音 → `iqmol_promo_zh.mp4`（含逐段校验，缺段即中止） |

```bash
# ① 环境准备（一次性）
bash scripts/video/setup_virtual_display.sh

# ② 常驻启动显示与窗口管理器（各自独立后台任务）
exec Xvfb :99 -screen 0 1920x1080x24 -nolisten tcp
DISPLAY=:99 openbox --sm-disable

# ③ 构建（若尚未构建）
cd build-video && cmake .. -DCMAKE_BUILD_TYPE=Release && make -j$(nproc)

# ④ 录屏
bash scripts/video/record_virtual_display.sh \
  src/Parser/test/samples/viagra.xyz build-video/out/demo.mp4 16
```

## 四、后期合成技术方案（已验证）

| 环节 | 工具 | 验证结果 |
|---|---|---|
| 视频编码 | ffmpeg `libopenh264`（H.264） | ✅ 实测通过（注：`libx264` 缺失，用 openh264 替代） |
| 中文字幕 | ffmpeg `drawtext` + Noto Sans CJK SC | ✅ 实测渲染正常 |
| Ken Burns 动效 | ffmpeg `zoompan` | ✅ 实测 125 帧 / 5 秒 / 1280×720 |
| 转场 | ffmpeg `xfade` | ✅ 滤镜可用 |
| BGM | ffmpeg 三振荡器和弦 + `afade` + `loudnorm I=-18` | ✅ 实测 AAC 输出，成片 **-17.1dB**（可听） |
| 合成编排 | Python + moviepy | ✅ 库可用 |

**字体**：`/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`（index 2 = Noto Sans CJK SC）

> ⚠️ **不要用 `DroidSansFallbackFull.ttf` 做字幕**（2026-10-02 实测踩坑）。
> 该字体在 PIL 下**不提供拉丁字形**，且缺 `·`（U+00B7）、`①②③`（U+2460-62）、`⭐`（U+2B50），
> 导致含英文/数字/间隔号/序号的中文一律渲染成**方框**——曾使数据条的
> `2112 / 153 / 34` 三个核心数字与收尾卡整行文字全部变方框。
>
> - `drawtext` 直接引用 `.ttc` 即可，**无需指定索引**（实测正常）
> - PIL 侧需 `ImageFont.truetype(path, size, index=2)` 显式指定 SC 子字体
> - `⭐` 需另配 `/usr/share/fonts/truetype/noto/NotoSansSymbols2-Regular.ttf`，
>   CJK 字体单独绘制该字符后再与文本拼接

**合成踩过的坑（已写进 `compose_main.sh` 注释）**

| # | 坑 | 解法 |
|---|---|---|
| 1 | `drawtext` 的 `text=` 不能用：中文逗号被滤镜链解析器当作分隔符，报 `No such filter: '0.6'` | 改走 `textfile=` |
| 2 | `amix` 之后未显式 `-map "[a]"` → ffmpeg 选不出输出流，BGM 生成 0 字节 | 显式 map |
| 3 | concat 清单用相对路径 → 被按**清单文件所在目录**解析，拼错路径 | 清单内一律绝对路径 |
| 4 | `-stream_loop` 对 1.5s 短输入无效 | 用滤镜级 `loop=loop=-1:size=32767` |
| 5 | 字幕字体用 `DroidSansFallbackFull.ttf` → 英文/数字/`·`/`①②③` 全渲染成方框 | 换 Noto Sans CJK SC，详见本节字体说明 |

## 五、分镜脚本（定稿）

| 段 | 时间 | 画面 | 字幕 |
|---|---|---|---|
| **1. 钩子** | 0–8s | **原版英文界面实拍快切 ×3**（`hero_viagra_en.mp4` 取 1s / 4.5s / 8s 三点，各 2.67s） | **A（主片 / 竖版）**「还在为英文界面头大？」<br>**B（B 站 / 学术版）**「分子建模，不必再啃英文手册」 |
| **2. 痛点** | 8–18s | 灰调背景 + 英文术语堆叠（Gaussian / ORCA 关键词） | 「教程翻三遍还是懵 · 菜单找不到 · 手册是英文」 |
| **3. 转折** | 18–28s | **英文界面 1.5s → 中文界面 8.5s 硬切**（已落地，非可选） | 「IQmol 中文版 · 全界面汉化」 |
| **4. 能力** | 28–55s | **真机录屏**分三组（规范见 5.1）：<br>▸ 建模：BuildMol（元素周期表 + 建模）<br>▸ 计算：QUI（计算设置）<br>▸ 可视化：Orbital / Density | 主标「建模 · 计算 · 可视化」<br>数据条「2112 条翻译 · 153 个界面模块 · 34 页中文手册」 |
| **5. 收尾** | 55–75s | 分子旋转实拍 + 收尾卡 | 上屏「开源免费 · GPL-3.0」<br>收尾卡：`https://github.com/stone-Glitch/IQmol-for-Chinese` + 二维码 + 「觉得好用，顺手点个 Star ⭐ 吧」 |

> **数据口径（2026-10-02 核实）**：`grep -c '<message' translations/zh_CN.ts` = 2112（0 unfinished），
> context 153，全仓 10+ 文档口径一致。`1519 / 111` 为 2026-09-13 历史快照，已废弃。
> 三个数字均可由观众打开 `.ts` 直接核验。
> 文中「153 个界面模块」与本节「153 个 context」为同一计数单位：
> 前者用于对外文案（更直观），后者用于对齐本仓库工程口径。

> **为何数据条不写「0 英文残留」**：静态管线存在假英文残留（见 2.3），
> 该论据留待真机录屏画面自证，不写入字幕。

> **为何开场必须用英文界面（2026-10-02 定稿）**
> 段 2 的痛点是「英文界面看不懂」，若段 1 直接给中文主界面，等于**开场就给答案**，痛点立不住。
> 故段 1 用 `Language=en` 实拍的原版英文界面，段 3 再硬切中文 —— 转折才有说服力。
> 注意两处英文性质不同：段 1 是**原版英文界面**（有意为之），段 4 QUI 对话框标题栏的英文是
> **独立组件未汉化**（见第九节风险表），不可混为一谈。

**30 秒精简版**：只留 1 + 3 + 5 三段，字幕同主片。**竖版**：文案复用，画幅改 1080×1920。

### 5.1 第 4 段真机录屏规范

| # | 要求 |
|---|---|
| 1 | 录 **3 个对话框，每个 ≤8s**：BuildMol → QUI → Orbital / Density，一一对应「建模 · 计算 · 可视化」 |

## 六、制作流程

```
① 素材预处理      裁剪 / 统一尺寸 / 去白边 → 工作副本
② 实机录屏        scripts/video/record_virtual_display.sh（逐镜头清单见 5.1 注）
③ 分镜脚本定稿     字幕文案 + 时长 + 素材映射表（见第五节）
④ 生成 BGM        程序合成和弦进行（C-G-Am-F 循环）
⑤ 分段渲染        每段独立 mp4（便于单段调整）
⑥ 拼接 + 字幕 + 混音  ffmpeg concat + drawtext + amix（含 loudnorm I=-18）
⑦ 出片            H.264 MP4，1920×1080 @25fps，实测 75.008s
⑧ 出片校验        ffprobe 查规格 + 抽帧 OCR 查字幕/角标 + volumedetect 查音量（实测 -17.1dB）
```

> 第 ⑧ 步不可省：本轮实际踩到过 BGM 音量 `0.03` 过小（成片 -55dB，几近静音）才发现，
> 靠 `volumedetect` 才暴露。合成完必须跑一遍。
