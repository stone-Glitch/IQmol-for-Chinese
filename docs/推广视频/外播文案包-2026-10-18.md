## 3. 知乎文章大纲

**标题候选**

1. 《我们把 IQmol 汉化成了中文：2110 条界面文本，一条一条核验过去》
2. 《化学老师的备课神器 IQmol，我把它的界面全汉化了（附中文手册）》
3. 《给一个开源科学软件做完整汉化是什么体验——以 IQmol 为例》

**结构**

1. **开头（个人钩子，200 字内）**：第一次用 IQmol 被全英文界面劝退的真实经历；
   引出"既然没人做，那就自己做"。
2. **IQmol 是什么**：开源分子编辑与可视化软件，GPL 协议，Q-Chem 官方图形前端；
   适合谁（化学教师备课 / 本科生结构化学 / 科研画图）。
3. **汉化做了什么**：2110 条界面文本 / 158 个界面模块 / 0 未完成 / 34 页中文手册；
   保留一键切回英文。
4. **怎么保证质量（差异化段落，知乎读者吃这套）**：
   - 译文逐条可核验——`translations/zh_CN.ts` 公开在仓库；
   - 三道 CI 门禁：TQA（空译文/未完成/术语）、tr() 覆盖率 100%、
     文档数字核验（README 写错数字都会挂）；
   - 发布带 SHA256SUMS，版本号从 CMakeLists 动态派生，不手写。
5. **怎么获取**：Releases 链接 + 仓库链接 + 国内镜像（就绪后补）。
6. **坦诚边界**：暂无 macOS 预编译包；欢迎提 Issue / PR，反馈邮箱。
7. **结尾 CTA**：需要什么功能 / 哪里译得别扭，评论区见。

**配图**：用 `docs/assets/ui/view3d_porphyrin.png` 作头图；
   中英界面对照截图见 `dialog_screenshots/`。**不要**用已移除的 viagra 素材。

## 4. 教师傻瓜包（outreach 用）

发给一位化学老师的最小材料集 = 下面四样，缺一不可：

| # | 材料 | 状态 |
|---|---|---|
| 1 | 一句话安利（见下方模板） | 本文档提供 |
| 2 | Windows 64 位安装包 zip | Releases 已就绪（v3.2.4.1-zh_CN） |
| 3 | 34 页中文手册 PDF | 随包附带（`doc/IQmolUserGuide.pdf`） |
| 4 | 反馈入口（邮箱 / Issues） | 见口径卡 |

**微信 / 邮件一句话模板**

> 「X 老师，之前您说画分子结构找不到顺手的免费软件，推荐试 IQmol 中文版：
> 菜单和对话框全中文，带 34 页中文手册，Windows 解压即用。
> 链接：<Releases 链接>。不好用您直接骂我，我收集反馈。」

**3 步上手（写给零基础用户）**

1. 下载 `IQmol-win64-3.2.4.1-zh_CN.zip`（Releases 页面置顶资产）；
2. 解压到任意目录（路径不要带中文和特殊字符）；
3. 双击 `IQmol.exe`；界面已是中文，右上角可一键切回英文。

**常见问题预案（提前备好答案，别让第一印象卡在安装）**

| 现象 | 答案 |
|---|---|
| 杀毒软件报错 | 开源软件无签名所致，加白名单即可；可先核对 SHA256SUMS |
| 提示缺 DLL | 安装 VC++ 运行库（手册排错章节有链接） |
| 找不到某功能 | 手册按界面模块组织，158 个模块都有中文对照 |
| 想要 macOS 版 | 暂无预编译包，可引导至仓库 Issues 投票 |
