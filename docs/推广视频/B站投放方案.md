## 三、B站版与通用版的差异

| 项 | 通用版（`iqmol_promo_zh.mp4`） | B站版（`iqmol_promo_bili.mp4`） |
|---|---|---|
| 前 8 秒 | 英文界面空场慢慢浮现 | **中英菜单交叉溶解（各停 2.2s，0.8s 溶解）→ 分屏对照** |
| 段4 演示 | 静态录屏 +角标 | **裁剪放大 + Ken Burns 推近 + 高亮框 + 说明字幕** |
| 段3 转折转场 | concat 硬切 | **0.5s 交叉溶解** |
| 静帧率 | 75% | **63%** |
| 适用 | 课题组内部分享、官网嵌入 | B站 / 知乎投递 |

段2/5 直接复用通用版成片，不重复渲染。段3 因转场改为溶解需重新生成。

**转场设计**（2026-10-02 二轮调整，用户反馈「转场太突然、中英闪太快」后重做）：

| 位置 | 做法 | 理由 |
|---|---|---|
| 开场中→英 | 0.8s 交叉溶解 | 原来 0.6s 硬切 4 下，像信号不良 |
| 开场段间 | 0.5s xfade 链式 | concat 拼接处亮度从 16 跳到 89，肉眼可见闪 |
| 开场→分子 | 分子段叠 22% 黑膜 | 亮界面（110）接深色卡片（40）会闪，压到 85 |
| 段3 转折 | 0.5s 交叉溶解 | 保留「突然变中文」的力度，但去掉生硬感 |

实测开场亮度曲线：31→31→31→34→41→50→85→85，全程平滑无跳变。
