## 为什么不是「机翻」

- **术语按领域规范处理**：如「弛豫密度」（非「松弛密度」）、「冻结核近似」等量子化学术语按规范统一。
- **保留快捷键与命令名**：熟练用户切到中文后手感不被打断。
- **一键切回英文**：偏好设置可在「中文 / English / 跟随系统」间切换（默认中文），便于与上游比对、排查误译。
- **覆盖全流程**：建模 → 计算 → 可视化全链路汉化。

> 说明：Q-Chem 对话框为独立第三方组件，其标题栏与部分菜单仍为英文，属上游固有，非汉化遗漏。
