# IQmol 中文版推广视频 · 拍摄分镜清单

> 用途：逐镜头给出可直接喂给 `scripts/video/record_virtual_display.sh`（或其对话框扩展版）执行的 `xdotool` 序列、时长、输出文件名。
> 前置：虚拟显示已常驻（Xvfb :99 + openbox），IQmol 二进制位于 `build-video/IQmol`。
> 硬约束：**键盘合成事件不可用 → 所有导航走鼠标**；菜单 x 坐标随窗口宽度浮动，录制前须一次现场校准（见附录）。
> 路径约定：下文所有路径与命令均**假设当前目录为仓库根目录**；输出 mp4 落盘后自行搬运到 `build-video/out/`。

## 0. 通用启动环境

```bash
export DISPLAY=:99
export LIBGL_ALWAYS_SOFTWARE=1
export QT_QPA_PLATFORM=xcb
export LANG=zh_CN.UTF-8 LC_ALL=zh_CN.UTF-8 LANGUAGE=zh_CN:zh
```

启动 IQmol（载入主视觉分子）：

```bash
./build-video/IQmol src/Parser/test/samples/viagra.xyz &
sleep 5   # 等 [i18n] Loaded translation: "zh_CN" + 渲染完成
```

## 2. 逐镜头操作序列

### 2.1 S3-EN / S3-ZH —— 原版英文 → 中文硬切

```bash
# 英文版（不加载中文翻译，即源码英文字符串）
LANGUAGE=en_US.UTF-8 LANG=en_US.UTF-8 ./build-video/IQmol \
  src/Parser/test/samples/viagra.xyz &
sleep 4
ffmpeg -y -f x11grab -s 1920x1080 -r 25 -i :99.0 -t 1.5 -c:v libopenh264 shot_3_en.mp4
pkill -f build-video/IQmol; sleep 1

# 中文版
LANGUAGE=zh_CN.UTF-8 LANG=zh_CN.UTF-8 ./build-video/IQmol \
  src/Parser/test/samples/viagra.xyz &
sleep 5   # 等 [i18n] Loaded translation: "zh_CN"
ffmpeg -y -f x11grab -s 1920x1080 -r 25 -i :99.0 -t 1.5 -c:v libopenh264 shot_3_zh.mp4
pkill -f build-video/IQmol
```

> 后期把 `shot_3_en.mp4` 与 `shot_3_zh.mp4` 做 1–2s 硬切，即「原版英文 → 中文界面」冲击力镜头。

### 2.2 S4A —— 建模 · BuildMol

已知最稳路径：工具栏「构建」C 按钮约在 `(265,50)` 可直接弹出元素周期表；菜单路径更直观但需校准坐标。

```bash
# 启动中文版并载入 viagra（见 0 节）
WIN=$(xdotool search --name IQmol | head -1)
xdotool windowactivate --sync $WIN

# 路径 A（推荐，免校准）：点工具栏 C 按钮直达 BuildMol 元素表
xdotool mousemove --sync 265 50; sleep 0.4; xdotool click 1; sleep 1.0

# 路径 B（菜单，需校准）：构建 → BuildMol
# xdotool mousemove --sync <构建_x> <menubar_y>; sleep 0.4; xdotool click 1; sleep 0.6
# xdotool mousemove --sync <buildmol_item_x> <buildmol_item_y>; sleep 0.4; xdotool click 1; sleep 1.0

# 动线表演：在周期表上滑过 + 点选 1–2 个元素
xdotool mousemove --sync <table_x0> <table_y0>
xdotool mousemove --sync <table_x1> <table_y1>
xdotool click 1

ffmpeg -y -f x11grab -s 1920x1080 -r 25 -i :99.0 -t 8 -c:v libopenh264 clip_4a_buildmol.mp4
pkill -f build-video/IQmol
```

### 2.3 S4B —— 计算 · QUI（Q-Chem 设置）

```bash
# 启动中文版（见 0 节）
WIN=$(xdotool search --name IQmol | head -1)
xdotool windowactivate --sync $WIN

# 计算 → Q-Chem 设置（全中文对话框）
xdotool mousemove --sync <计算_x> <menubar_y>; sleep 0.4; xdotool click 1; sleep 0.6
xdotool mousemove --sync <qchem_item_x> <qchem_item_y>; sleep 0.4; xdotool click 1
sleep 1.0   # QUI 对话框弹出

ffmpeg -y -f x11grab -s 1920x1080 -r 25 -i :99.0 -t 8 -c:v libopenh264 clip_4b_qui.mp4
pkill -f build-video/IQmol
```

### 2.4 S4C —— 可视化 · Orbital / Density

## 3. 附录：一次现场坐标校准

菜单栏 x 坐标因字体 / 窗口宽度不同而变化，录制前跑一次，将读到的 x 回填到上面的 `<..._x>` 占位符：

```bash
WIN=$(xdotool search --name IQmol | head -1)
xdotool getwindowgeometry $WIN          # 拿窗口左上角与尺寸
# 手动把指针移到各菜单标题中心，记录 x（menubar_y 一般 ≈ 30）：
xdotool mousemove 560 30; xdotool getmouselocation   # 构建
xdotool mousemove 640 30; xdotool getmouselocation   # 计算
# 下拉子项：先点开菜单，再把指针移到目标子项中心记录坐标
```

工具栏「构建」C 按钮在 `(265,50)` 已实测，无需校准（S4A 路径 A）。

## 4. 校验门槛（防假英文）

每段录制前确认 IQmol 启动日志出现 `[i18n] Loaded translation: "zh_CN"`：
- 缺失 → 说明没加载中文翻译，画面会是英文，必须重跑（检查 `LANGUAGE` / `zh_CN.qm` 是否就位）。
- 这一条是「真机全中文」的权威判据，比肉眼看菜单更可靠。
