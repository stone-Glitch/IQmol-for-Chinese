# 翻译对照表

本目录是 IQmol 中文本地化项目的**翻译对照表总入口**，记录每处改动的
**原文 / 译文 / 修改理由 / 责任人**，用于译法追溯、术语校对与后续维护。

> 项目规范要求：所有产出（翻译对照表、问题报告、修改建议）应使用结构化
> Markdown，并清晰包含原文、译文、修改理由、责任人。

## 维护约定

- 新增或修改翻译时，同步更新对应对照表，**不得只改 `.ts` / 数据库而不留记录**。
- 术语须遵循全国科学技术名词审定委员会官方译法，并保持全表一致。
- 译法有争议时，先在对照表中标注「待术语确认」，建任务讨论后再定稿。
- 译文条数的权威口径是 `translations/zh_CN.ts` 的 `<message>` 计数
  （当前 **2112 条 / 153 个 context**），文档中的数字以该源文件为准。
