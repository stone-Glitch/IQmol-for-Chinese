诚实的边界
· Q-Chem 是独立第三方组件，其对话框标题栏与 File / Edit / Job / Font 菜单仍为英文，不在汉化范围内。
· 上游源码中少量未走 tr() 包裹的运行期字符串（如历史记录中的 Repersceive bonds）仍会显示英文，属上游固有结构问题。
· 仅实测 Windows x64 与 Linux x86_64，macOS 未构建验证。
