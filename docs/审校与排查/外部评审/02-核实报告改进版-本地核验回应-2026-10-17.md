## 二、重点纠正（报告的"未验证/缺陷"项在本地已被解决或降级）

1. **F-03 降级为"一致"**：报告的担忧（"GPLv3 文本不等于 or-later，SBOM 不应自行扩展"）在只看 `LICENSE` 全文时成立；但本地每个源文件版权头都书面声明 *"either version 3 … or any later version"*。因此 `GPL-3.0-or-later` **有版权头背书**，SBOM 未越界。**建议**：无需"二选一"，可在 `LICENSE` 顶部或 README 补一句 SPDX 标注（`SPDX-License-Identifier: GPL-3.0-or-later`）提升透明度即可。
2. **F-04 已解决（P2-8）**：9 子模块已 commit 锁定 + `MANIFEST.json` + 漂移门禁。报告评审的远程 main 快照（10-16）尚未反映此整改。
3. **F-06 已解决（P1-6）**：`RELINKING-NOTICE.md` 已交付。报告"未找到"指向远程 main 未合入该整改。

> 共性原因：报告基于**远程 main**，而本地 `user-feedback-improvements` 分支的整改尚未全部合入远程 main（且当前 GitHub 未连接，无法确认远程状态）。
