## 四、需授权 / 外部依赖的动作（本机无法独立完成）

- **GitHub Token**：重发 Release 修正资产命名 + 同步 `SHA256SUMS.txt`；拉取远程 CI 运行记录补全三平台证据（`gh` 未登录）。

- **macOS 工作流**：新增 `macos-latest` 构建+打包工作流草案。
- **签名/provenance**：Ed25519 签名 `SHA256SUMS.txt` + 公钥固定；或 Cosign/SLSA（需托管密钥）。
- **安全扫描门禁**：CI 增加 gitleaks / trufflehog（需预装或 action）。
- **`submodules-package` 49,335 文件 / MD5 声明**：离线包未下载，无法独立复核（仅建议升级为 SHA-256）。
