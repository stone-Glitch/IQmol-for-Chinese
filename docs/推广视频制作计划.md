### 2.2 缺口（阻塞项）

> ⚠️ **缺一张「载入分子后的完整中文主界面」截图**

现有主界面截图全部是**空视图**（蓝色背景、无分子），且 `dialog_screenshots/Viewer_zh.png`
是**旧版半汉化残留**（`Model View` / `Global` / `Untitled` 仍是英文），
用于视频会**自相矛盾**。

**需要的图**（1 张即可，2 张更好）：

| 优先级 | 内容 | 用途 |
|---|---|---|
| **必需** | 载入分子后的主界面，菜单栏 + 左侧模型视图 + 右侧分子视图全中文 | 开场/结尾主画面 |
| 可选 | 显示分子轨道（Orbitals）后的界面 | 能力展示段 |

**拍摄建议**：
- 载入 `samples/` 下的分子（如 `caffeine.xyz` 或 `Benzene`）
- 展开左侧「模型视图」树，让层级文字可见
- 在「显示」菜单里打开一个面板（如分子轨道），使界面不空
- 分辨率 ≥ 1920×1080，PNG 无损

## 三、技术方案（已验证）

| 环节 | 工具 | 验证结果 |
|---|---|---|
| 视频编码 | ffmpeg `libopenh264`（H.264） | ✅ 实测通过（注：`libx264` 缺失，用 openh264 替代） |
| 中文字幕 | ffmpeg `drawtext` + Droid Sans Fallback | ✅ 实测渲染正常 |
| Ken Burns 动效 | ffmpeg `zoompan` | ✅ 实测 125 帧 / 5 秒 / 1280×720 |
| 转场 | ffmpeg `xfade` | ✅ 滤镜可用 |
| BGM | ffmpeg 正弦和弦合成 + `afade` | ✅ 实测 AAC 输出正常 |
| 合成编排 | Python + moviepy | ✅ 库可用 |

**字体**：`/usr/share/fonts/truetype/droid/DroidSansFallbackFull.ttf`
（备选：`uming.ttc`、`NotoSansCJK-Regular.ttc`——注意 `.ttc` 字体集在 drawtext 中需指定索引）

## 四、脚本结构（75 秒）

| 段 | 时长 | 画面 | 字幕（草案） |
|---|---|---|---|
| **1. 钩子** | 0–8s | 分子渲染快速闪切：Benzene → CHF3 五风格 → ESP | 「分子建模 不必再对着英文界面」 |
| **2. 痛点** | 8–18s | 灰调背景 + 英文术语堆叠（Gaussian/ORCA 关键词） | 「术语看不懂 · 菜单找不到 · 手册是英文」 |
| **3. 转折** | 18–28s | **中文主界面**（待补图）+ 标题浮出 | 「IQmol 中文版 · 全界面汉化」 |
| **4. 能力** | 28–55s | 分 3 组快切：<br>▸ 建模：BuildMol / MoleculeConfigurator<br>▸ 计算：QUI / JobMonitor / ServerDialog<br>▸ 可视化：Orbital / ESP / NmrDisplay / PES | 「建模 · 计算 · 可视化」三组小标题 + 数据「2112 条翻译 · 153 个模块」 |
| **5. 收尾** | 55–75s | 卡片堆叠成墙（展示覆盖广度）+ 仓库地址 | 「开源免费 · GPL-3.0 · 立即下载」 |

**附加产出**：
- 30 秒精简版（钩子 + 转折 + 收尾）
- 1080×1920 竖版（适配小红书/抖音，可选）

## 五、制作流程

```
① 素材预处理          裁剪/统一尺寸/去白边 → 工作副本
② 补图确认            ⬅ 等你提供主界面截图
③ 分镜脚本定稿         字幕文案 + 时长 + 素材映射表
④ 生成 BGM            程序合成和弦进行（C-G-Am-F 循环）
⑤ 分段渲染            每段独立 mp4（便于单段调整）
⑥ 拼接 + 字幕 + 混音    ffmpeg concat + drawtext + amix
⑦ 出片                H.264 MP4，1920×1080 @25fps
```
