## 三、虚拟窗口录屏方案（已实测验证）

### 3.1 原理

无显卡/无物理显示器的环境里，用三层软件栈模拟出一个真实桌面：

```
Xvfb（虚拟 X 显示，1920×1080）
  └─ Mesa llvmpipe（CPU 软件 OpenGL，实测 4.5 Compatibility Profile）
       └─ openbox（窗口管理器，必需 —— 见 3.3 坑 1）
            └─ IQmol（真实二进制，中文界面）
                 └─ ffmpeg x11grab（抓屏录制）
```

### 3.2 验证结果

| 环节 | 结果 |
|---|---|
| Qt5 OpenGL 上下文创建 | ✅ `context_created: true`，`makeCurrent: true` |
| GL 版本 | ✅ **4.5 Compatibility Profile**（Mesa 25.2.8 / llvmpipe / LLVM 20.1.2） |
| IQmol 着色器编译 | ✅ Cel / Gooch / Gouraud / Phong / Plastic **5 个全部成功** |
| 中文界面 | ✅ 日志 `[i18n] Loaded translation: "zh_CN"`；菜单栏「文件 编辑 显示 构建 计算 帮助」 |
| 中文渲染（无方块） | ✅ Noto Sans CJK SC / Droid Sans Fallback 均正常 |
| 分子渲染 | ✅ 球棍模型（西地那非）、蛋白二级结构（3nir）均正常 |
| 录屏 | ✅ H.264 / 1920×1080 / 25fps，帧间可见分子旋转 |
| zh_CN locale | ✅ `locale-gen` 后 `date` 输出「2026年 10月 02日 星期五」 |

### 3.3 踩过的坑（已固化进脚本）

| # | 坑 | 现象 | 解法 |
|---|---|---|---|
| **1** | **缺窗口管理器** | 截图里窗口只占屏幕左上角一块，`xdotool windowsize` 无效 | 启动 **openbox**；无 WM 时 Qt 的 resize 请求不被落实 |
| **2** | 误禁 GLX | `Cannot create platform OpenGL context, neither GLX nor EGL are enabled` | **不要**设 `QT_XCB_GL_INTEGRATION=none`；用 `xcb_glx` |
| **3** | 后台进程被回收 | Xvfb 起来又消失，`unable to open display` | Xvfb / openbox 必须放**独立后台任务**常驻；普通 `&` 会随会话结束被带走 |
| **4** | locale 未生成 | `setlocale: LC_ALL: cannot change locale (zh_CN.UTF-8)` | 先 `locale-gen zh_CN.UTF-8` |
| **5** | 判断"中文是否生效"靠肉眼 | 界面看着是中文，但不确定 | 认日志 `[i18n] Loaded translation: "zh_CN"`，这是权威标志 |
| **6** | 全量编译中途静默中断 | 日志无错误、无 OOM，突然停在某文件 | 沙箱会话回收所致；重跑 `make` 会自动续上（已编译的不重编） |

### 3.4 脚本

| 脚本 | 用途 |
|---|---|
| `scripts/video/setup_virtual_display.sh` | 校验依赖 + 生成 zh_CN locale + 打印常驻启动命令 |
| `scripts/video/record_virtual_display.sh` | **主脚本**：启动 IQmol → 等中文加载 → 视图居中 → 录屏 + 鼠标旋转分子 |

用法：

```bash
# ① 环境准备（一次性）
bash scripts/video/setup_virtual_display.sh

# ② 常驻启动显示与窗口管理器（各自独立后台任务）
exec Xvfb :99 -screen 0 1920x1080x24 -nolisten tcp
DISPLAY=:99 openbox --sm-disable

# ③ 构建（若尚未构建）
cd build-video && cmake .. -DCMAKE_BUILD_TYPE=Release && make -j$(nproc)

# ④ 录屏
bash scripts/video/record_virtual_display.sh \
  src/Parser/test/samples/viagra.xyz build-video/out/demo.mp4 16
```

## 五、脚本结构（75 秒）

| 段 | 时长 | 画面 | 字幕（草案） |
|---|---|---|---|
| **1. 钩子** | 0–8s | 分子渲染快速闪切：Benzene → CHF3 五风格 → ESP | 「分子建模 不必再对着英文界面」 |
| **2. 痛点** | 8–18s | 灰调背景 + 英文术语堆叠（Gaussian/ORCA 关键词） | 「术语看不懂 · 菜单找不到 · 手册是英文」 |
| **3. 转折** | 18–28s | **自产中文主界面**（2.2）+ 标题浮出 | 「IQmol 中文版 · 全界面汉化」 |
| **4. 能力** | 28–55s | 分 3 组：<br>▸ 建模：BuildMol / MoleculeConfigurator<br>▸ 计算：QUI / JobMonitor / ServerDialog<br>▸ 可视化：Orbital / ESP / NmrDisplay / PES | 「建模 · 计算 · 可视化」+ 数据「2112 条翻译 · 153 个模块」 |
| **5. 收尾** | 55–75s | **实机录屏：分子旋转**（3.4 产物）+ 仓库地址 | 「开源免费 · GPL-3.0 · 立即下载」 |

> **相对原计划的升级**：第 3 段与第 5 段由「静态截图 + Ken Burns」升级为
> **实机录屏**（含真实分子旋转），观感上限显著提高。

**附加产出**：
- 30 秒精简版（钩子 + 转折 + 收尾）
- 1080×1920 竖版（适配小红书/抖音，可选）

## 六、制作流程

```
① 素材预处理          裁剪/统一尺寸/去白边 → 工作副本
② 实机录屏           ⬅ 新方案：scripts/video/record_virtual_display.sh
③ 分镜脚本定稿         字幕文案 + 时长 + 素材映射表
④ 生成 BGM            程序合成和弦进行（C-G-Am-F 循环）
⑤ 分段渲染            每段独立 mp4（便于单段调整）
⑥ 拼接 + 字幕 + 混音    ffmpeg concat + drawtext + amix
⑦ 出片                H.264 MP4，1920×1080 @25fps
```
