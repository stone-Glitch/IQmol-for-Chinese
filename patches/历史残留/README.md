## 更正（2026-10-03）：F1 的 8 处字符串其实漏网了

原说明称"改动已并入 `功能补丁-*`"，**对这 8 处不成立**。经逐串 grep 核实：
- `功能补丁-构建层.patch` / `界面资源.patch` / `语言支持.patch` / `非机械改动.patch` 四件套中，F1 的 8 个字符串（`Reperceive bonds`、`Remove atoms/bonds`、`Translate to center`、`Add EFP fragment`、`Add molecule`、`Move items`、`Add Charges`、`Minimize energy`、`Symmetrize structure`）**全部 0 命中**。
- 这 8 处仅存在于本目录的 `补丁-历史记录未翻译字符串.patch`（精准）与 `补丁-未翻译字符串全量.patch`（含其中 7 处）。
- 因此发布版 `v3.2.3-zh_CN` 的「历史记录」面板仍显示英文，F1 缺陷**尚未真正修复**。

**修复路径（供下一版）**：把 `补丁-历史记录未翻译字符串.patch` 的 8 处 `tr()` 增补合并进 `../功能补丁-非机械改动.patch`，
随后 `lupdate` → 补 9 条译文 → `lrelease` → 重打包。合并完成、确认生效后再整体删除本目录。

## 为何保留而非删除

保留在此处是为了保留"当初是怎么发现并修补这些残留的"过程证据，便于审计"哪些字符串是何时补的"。在 F1 的 8 处尚未迁移进生效补丁集之前，**不要删除本目录**。

> 当前生效的迁移/构建补丁只有 `../` 下 `功能补丁-*` 四件套（构建层 / 界面资源 / 语言支持 / 非机械改动），以及对应的 `.meta.json` 元数据。F1 的 8 处是已知漏网项，正在补齐。
