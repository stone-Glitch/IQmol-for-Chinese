## 为何保留而非删除

这两份补丁改动涉及的 `.C/.ui` 源文件（如 `ConstraintConfigurator.C`、`MullikenDecompositionsDialog.C`、`SurfaceAnimatorDialog.C`、`CubeDataLayer.C`、`GeminalOrbitalsLayer.C`、`MoleculeLayer.C` 等）**全部已包含在 `../功能补丁-*.patch` 中，且后者更完整**（额外覆盖 `.ui` 界面文本与构建层修复）。

保留在此处是为了保留"当初是怎么发现并修补这些残留的"过程证据，便于审计"哪些字符串是何时补的"。若确认不再需要，可整体删除本目录。

> 当前生效的迁移/构建补丁只有 `../` 下 `功能补丁-*` 四件套（构建层 / 界面资源 / 语言支持 / 非机械改动），以及对应的 `.meta.json` 元数据。
