# IQmol 子模块离线包（Windows 用户专用）

GitHub 子模块仓库体积大、国内网络经常断连（`git submodule update` 卡在 6%、
或 `Failed to connect to github.com:443`），所以这里提供**打包好的完整子模块源码**：
下载 → 解压到仓库根目录 → 直接构建，完全跳过联网克隆。

## 一、下载（就 2 个文件）

| 文件 | 大小 | 用途 |
|------|------|------|
| **`IQmol-submodules.tar.gz`** | **73 MB** | 完整子模块源码（单文件，不用合并） |
| `extract_submodules.bat` | 3.5 KB | 校验 + 解压脚本（推荐一起下） |

Windows 10/11 自带 `tar.exe` 就能解压，360压缩 / 7-Zip / WinRAR 也都支持。

## 二、操作步骤

### 1. 把两个文件放同一个文件夹

例如 `D:\Downloads\`，里面应该有：

```
IQmol-submodules.tar.gz
extract_submodules.bat
```

### 2. 双击 `extract_submodules.bat`

它会：检查文件在不在 → 校验大小和 MD5 → 提示解压命令。
校验不通过会明确告诉你是哪个文件没下全。

### 3. 带路径运行，一步解压到位

在 **cmd 命令提示符**里（不是 PowerShell，看提示符：`C:\>` 是 cmd，`PS C:\>` 是 PowerShell）：

```bat
cd /d D:\Downloads
extract_submodules.bat "D:\IQmol"
```

把 `"D:\IQmol"` 换成你**仓库根目录**的实际路径。

> ⚠️ **强烈建议仓库放在短路径下**，比如 `D:\IQmol`。
> Windows 有 260 字符路径上限，子模块源码目录层级很深，
> 路径太长会在解压时报 `filename too long` 之类的错误。

### 4. 手动版（不用脚本）

**MSYS2 终端（最稳，推荐）：**

```bash
cd /d/IQmol
tar -xzf /d/Downloads/IQmol-submodules.tar.gz
```

**Windows cmd / PowerShell：**

```bat
cd /d D:\IQmol
tar -xzf D:\Downloads\IQmol-submodules.tar.gz
```

**校验（可选）：**

```bat
certutil -hashfile IQmol-submodules.tar.gz MD5
```

| 项目 | 值 |
|------|-----|
| 大小 | **75,759,260** 字节 |
| MD5  | **9c0ed6e3527cf0dd1c8d5628cc31538f** |

对不上就是没下全，重新下载即可（支持续传）。

## 三、验证解压结果

```bat
dir modules
```

应该看到 9 个目录：

```
HighFive  hdf5  libarchive  libQGLViewer  libssh2  libxml2  openbabel  openmesh  yaml-cpp
```

再确认关键文件在：

```bat
dir modules\hdf5\CMakeLists.txt
dir modules\openbabel\CMakeLists.txt
dir modules\yaml-cpp\CMakeLists.txt
```

> 压缩包内部顶层就是 `modules\`，所以**必须解压到仓库根目录**，
> 不是解压到 `modules` 里面——这样才会和仓库已有的 `modules` 目录合并。

## ⚠️ 三个坑

1. **别再跑 `git submodule update --init --recursive`** — 会重新联网克隆，覆盖掉刚解压的文件。
2. **之前克隆失败留过半截目录的**，先清理再解压：
   ```bat
   git submodule deinit -f --all
   ```
3. **路径别太长** — 仓库放 `D:\IQmol` 这种短路径，别放
   `D:\我的文档\项目\化学软件\IQmol-for-Chinese\...`。
