# IQmol 子模块离线包（Windows 用户专用）

因为 GitHub 子模块仓库体积大、国内网络经常断连，这里提供**打包好的完整子模块源码**，
下载后直接解压到仓库 `modules/` 目录，即可跳过 `git submodule update` 这一步。

## 一、下载

本目录下共 4 个文件，都需要下载：

| 文件 | 大小 | 用途 |
|------|------|------|
| `part_00` | 45 MB | 分片 1/3 |
| `part_01` | 45 MB | 分片 2/3 |
| `part_02` | 18 MB | 分片 3/3 |
| `merge_submodules.bat` | 4 KB | 合并+校验+解压脚本（推荐下载） |

下载方式：在 GitHub 文件列表里点文件名 → 右上角 **`Download raw file`**（下载原始文件）。

如果浏览器下载慢，把链接前面加上国内镜像前缀即可加速，例如：

```
https://ghfast.top/https://github.com/stone-Glitch/IQmol-for-Chinese/raw/refs/heads/submodules-package/part_00
```

三个分片都换成同样的前缀即可。

## 二、合并成一个 zip

把 3 个分片放到同一个文件夹（例如 `D:\Downloads`），然后：

### 方式 A：用现成脚本（推荐，双击即可）

把同目录下的 **`merge_submodules.bat`**（与分片在同一个分支列表里，一并下载）
也放到分片所在文件夹，**双击运行**，它会自动完成：

1. 检查 3 个分片是否齐全（缺哪个会明确报出来）
2. 合并成 `IQmol-submodules.zip`
3. 校验大小（112,618,126 字节）和 MD5（`787d6023...`），不通过会报错并提示重下
4. 可选：直接解压到仓库根目录

想连解压一起做，在 **cmd 命令提示符**里带仓库路径运行（注意是 cmd，不是 PowerShell）：

```bat
cd /d D:\Downloads
merge_submodules.bat "D:\你的路径\IQmol-for-Chinese"
```

> 脚本是纯 ASCII 的，不会中文乱码。

### 方式 B：手动敲命令

**Windows（命令提示符 cmd）：**

```bat
cd /d D:\Downloads
copy /b part_00 + part_01 + part_02 IQmol-submodules.zip
```

**Windows（PowerShell）：**

```powershell
cd D:\Downloads
Get-Content part_00,part_01,part_02 -Encoding Byte -ReadCount 0 | Set-Content IQmol-submodules.zip -Encoding Byte
```

**Linux / macOS / MSYS2 终端：**

```bash
cat part_00 part_01 part_02 > IQmol-submodules.zip
```

## 三、校验（强烈建议）

合并后的 `IQmol-submodules.zip` 必须满足：

| 项目 | 值 |
|------|-----|
| 大小 | 112,618,126 字节（约 108 MB） |
| MD5  | `787d6023c5ec715ec0334427da4baa75` |

**Windows 校验 MD5（PowerShell）：**

```powershell
(Get-FileItemHash IQmol-submodules.zip -Algorithm MD5).Hash
```

**Windows 校验 MD5（cmd）：**

```bat
certutil -hashfile IQmol-submodules.zip MD5
```

**Linux / MSYS2：**

```bash
md5sum IQmol-submodules.zip
```

输出的 MD5 与上面表格一致，说明合并正确，可以继续；不一致说明某个分片下载不完整，请重新下载。

## 四、解压到仓库

压缩包内部结构是：

```
modules/
├── HighFive/
├── hdf5/
├── libarchive/
├── libQGLViewer/
├── libssh2/
├── libxml2/
├── openbabel/
├── openmesh/
└── yaml-cpp/
```

所以**要解压到仓库根目录**（不是解压到 `modules` 里面），让 `modules\` 这一层和仓库已有的 `modules` 目录合并。

**Windows（PowerShell，推荐，会自动覆盖合并）：**

```powershell
cd D:\你的路径\IQmol-for-Chinese
Expand-Archive -Path D:\Downloads\IQmol-submodules.zip -DestinationPath . -Force
```

**或用资源管理器**：右键 zip → 全部解压缩 → 目标选仓库根目录 → 遇到"是否合并/替换"选**全部选是**。

**MSYS2 / Linux：**

```bash
cd /d/你的路径/IQmol-for-Chinese
unzip -o /d/Downloads/IQmol-submodules.zip
```

## 五、验证

解压完成后，检查 9 个目录都有内容（每个目录下应该有 `CMakeLists.txt` 或 `configure.ac` 之类）：

```bat
dir modules
```

应该看到 9 个目录。然后确认关键文件存在：

```bat
dir modules\hdf5\CMakeLists.txt
dir modules\openbabel\CMakeLists.txt
dir modules\yaml-cpp\CMakeLists.txt
```

## 六、之后就可以正常构建了

```bat
cd /d D:\你的路径\IQmol-for-Chinese
scripts\build_windows.bat
```

> **注意**：此时**不要**再执行 `git submodule update --init --recursive`，
> 否则 git 会尝试重新联网克隆覆盖掉你刚解压好的文件。
> 如果之前子模块克隆失败过、残留了半截目录，先在仓库根目录执行清理：
> ```bat
> git submodule deinit -f --all
> ```
> 再解压本离线包。
