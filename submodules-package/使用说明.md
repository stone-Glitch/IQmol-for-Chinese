# IQmol 子模块离线包（Windows 用户专用）

GitHub 子模块仓库体积大、国内网络经常断连（`git submodule update` 卡在 6%、
或 `Failed to connect to github.com:443`），所以这里提供**打包好的完整子模块源码**：
下载 → 解压到仓库根目录 → 直接构建，完全跳过联网克隆。

## 一、选一个包下载（二选一，不用都下）

### ★ 方案 A：单文件 `IQmol-submodules.tar.gz`（推荐）

**73 MB，下一个文件就完事，不用合并。** Windows 10/11 自带 `tar.exe` 就能解压。

| 文件 | 大小 | 用途 |
|------|------|------|
| **`IQmol-submodules.tar.gz`** | **73 MB** | 完整子模块源码（单文件） |
| `extract_submodules.bat` | 3.5 KB | 校验 + 解压脚本（推荐一起下） |

下载链接（右键新标签打开，或在文件页点 **Download raw file**）：

```
https://github.com/stone-Glitch/IQmol-for-Chinese/raw/refs/heads/submodules-package/submodules-package/IQmol-submodules.tar.gz
https://github.com/stone-Glitch/IQmol-for-Chinese/raw/refs/heads/submodules-package/submodules-package/extract_submodules.bat
```

**国内镜像加速**（下载慢时，把 `https://github.com/` 换成 `https://ghfast.top/https://github.com/`）：

```
https://ghfast.top/https://github.com/stone-Glitch/IQmol-for-Chinese/raw/refs/heads/submodules-package/submodules-package/IQmol-submodules.tar.gz
```

> 实测镜像约 1.4 MB/s，且**支持断点续传**（HTTP 206），下了一半断了能续。

### 方案 B：分卷 zip（备选）

如果 73 MB 单文件下载总是失败，改用分卷版（共 108 MB，需下载 3 片再合并）：
`part_00`(45 MB) + `part_01`(45 MB) + `part_02`(18 MB) + `merge_submodules.bat`。
用法见本文末尾「附录：分卷版用法」。

## 二、方案 A 操作步骤

### 1. 把两个文件放同一个文件夹

例如 `D:\Downloads\`，里面应该有：

```
IQmol-submodules.tar.gz
extract_submodules.bat
```

### 2. 双击 `extract_submodules.bat`

它会：检查文件在不在 → 校验大小和 MD5 → 提示解压命令。
校验不通过会明确告诉你是哪个文件没下全。

### 3. 带路径运行，一步解压到位

在 **cmd 命令提示符**里（不是 PowerShell，看提示符：`C:\>` 是 cmd，`PS C:\>` 是 PowerShell）：

```bat
cd /d D:\Downloads
extract_submodules.bat "D:\IQmol"
```

把 `"D:\IQmol"` 换成你**仓库根目录**的实际路径。

> ⚠️ **强烈建议仓库放在短路径下**，比如 `D:\IQmol`。
> Windows 有 260 字符路径上限，子模块源码目录层级很深，
> 路径太长会在解压时报 `filename too long` 之类的错误。

### 4. 手动版（不用脚本）

**MSYS2 终端（最稳，推荐）：**

```bash
cd /d/IQmol
tar -xzf /d/Downloads/IQmol-submodules.tar.gz
```

**Windows cmd / PowerShell：**

```bat
cd /d D:\IQmol
tar -xzf D:\Downloads\IQmol-submodules.tar.gz
```

**校验（可选）：**

```bat
certutil -hashfile IQmol-submodules.tar.gz MD5
```

| 项目 | 值 |
|------|-----|
| 大小 | **75,759,260** 字节 |
| MD5  | **9c0ed6e3527cf0dd1c8d5628cc31538f** |

对不上就是没下全，重新下载即可（支持续传）。

## 三、验证解压结果

```bat
dir modules
```

应该看到 9 个目录：

```
HighFive  hdf5  libarchive  libQGLViewer  libssh2  libxml2  openbabel  openmesh  yaml-cpp
```

再确认关键文件在：

```bat
dir modules\hdf5\CMakeLists.txt
dir modules\openbabel\CMakeLists.txt
dir modules\yaml-cpp\CMakeLists.txt
```

> 压缩包内部顶层就是 `modules\`，所以**必须解压到仓库根目录**，
> 不是解压到 `modules` 里面——这样才会和仓库已有的 `modules` 目录合并。

cd /d D:\IQmol

## ⚠️ 三个坑

1. **别再跑 `git submodule update --init --recursive`** — 会重新联网克隆，覆盖掉刚解压的文件。
2. **之前克隆失败留过半截目录的**，先清理再解压：
   ```bat
   git submodule deinit -f --all
   ```
3. **路径别太长** — 仓库放 `D:\IQmol` 这种短路径，别放
   `D:\我的文档\项目\化学软件\IQmol-for-Chinese\...`。

## 附录：分卷版（方案 B）用法

只有单文件版下载不了时才用这个。

**下载 4 个文件**（同一分支目录）：`part_00`、`part_01`、`part_02`、`merge_submodules.bat`。

**双击 `merge_submodules.bat`** 即可自动合并+校验，或在 cmd 里带路径一步做完：

```bat
cd /d D:\Downloads
merge_submodules.bat "D:\IQmol"
```

手动合并（cmd）：

```bat
copy /b part_00 + part_01 + part_02 IQmol-submodules.zip
```

PowerShell（**必须分两行、一条一条回车**，粘成一整行会失败）：

```powershell
Get-Content part_00,part_01,part_02 -Encoding Byte -ReadCount 0 |
  Set-Content IQmol-submodules.zip -Encoding Byte
```

分卷版校验值：大小 `112,618,126` 字节，MD5 `787d6023c5ec715ec0334427da4baa75`。
