## 下载

### 方式一：ghfast.top 镜像（国内推荐）

```bash
curl -L -o IQmol-linux-x86_64.tar.gz \
  "https://ghfast.top/https://raw.githubusercontent.com/stone-Glitch/IQmol-for-Chinese/submodules-package/submodules-package/linux-build/IQmol-linux-x86_64.tar.gz"
```

### 方式二：GitHub 直连（海外/可访问 GitHub 时）

```bash
curl -L -o IQmol-linux-x86_64.tar.gz \
  "https://raw.githubusercontent.com/stone-Glitch/IQmol-for-Chinese/submodules-package/submodules-package/linux-build/IQmol-linux-x86_64.tar.gz"
```

> 大文件下载建议加 `--retry 3 -C -` 支持断点续传。

## 使用

```bash
tar xzf IQmol-linux-x86_64.tar.gz
cd IQmol-linux-x86_64
./run.sh
```

首次运行会自动配置资源路径，无需 `sudo`、不污染系统。

## 说明

- 本包为 **Linux 版**。Windows 版需在 Windows + MSYS2 MinGW64 环境下用
  `scripts/build_windows.sh` 编译，编译完成后用 `scripts/deploy_windows.sh` 部署。
- IQmol 遵循 GPLv3，本包为 GPL 衍生作品，同样遵循 GPLv3。
