## 一、概述

### 核查背景

`translations/zh_CN.ts` 现有 **2106 条、0 unfinished、0 vanished**（全部完成）。但 `lupdate`
只能提取**已被 `tr()` 包裹**的字符串——源码中若直接写死英文（未包 `tr()`），`lupdate` 扫不到，
翻译文件里自然也没有，界面上就会显示英文。本次核查即针对这类「漏网」字符串。

### 扫描方法

对 `src/` 下 **292 个 `.C` 源文件 + 82 个 `.ui` 文件**做静态扫描：

| 扫描对象 | 方式 |
|---|---|
| UI 函数调用（`setText` / `setWindowTitle` / `setLabel` / `addAction` 等） | 正则匹配「函数名后紧跟裸字符串字面量」，自动排除 `tr("...")` 包裹的情况 |
| `QMessageBox::information/warning/critical/question` | 提取括号内全部字符串字面量，排除 `tr()` 包裹项 |
| 菜单类（`new QAction("...")` / `addMenu` / `addSection` / `QMenu`） | 同上 |
| `.ui` 文件 | 提取 `<string>` 内容，与 `zh_CN.ts` 的 source 集合比对 |

### 结果统计

| 类别 | 数量 | 处理 |
|---|---|---|
| UI 函数硬编码（`.C`） | 60 | **需译** |
| `QAction` 菜单项硬编码（去重后） | 5 | **需译** |
| `.ui` 文件遗漏（剔除样式表/单位后） | 约 6 | **需译** |
| 明确不译项（Q-Chem 关键字 / 单位符号 / QSS 样式表 / HTML 标签） | 约 25 | 排除 |
| **合计需处理** | **约 71** | |
