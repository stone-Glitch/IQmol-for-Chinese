> Markdown，并清晰包含原文、译文、修改理由、责任人。

### 2. `汉化扩展-硬编码字符串tr包裹.md`

第 2 阶段工作，针对直接传给 `setText` / `setWindowTitle` / `QUndoCommand` 等
UI 函数、因而 `lupdate` 扫不到的硬编码字符串。

| 指标 | 数值 |
|---|---|
| 修改源文件数 | 18 |
| 新增 `tr()` 包裹点 | 45 |
| 新增翻译源串 | 41 条 |

> 技术要点：非 `QObject` 派生的 `UndoCommands` 类改用
> `QCoreApplication::translate("UndoCommands", ...)`，以保证 `lupdate`
> 可提取且运行时可翻译。品牌名 `IQmol` 保留原文。

## 维护约定

- 新增或修改翻译时，同步更新对应对照表，**不得只改 `.ts` 而不留记录**。
- 术语须遵循全国科学技术名词审定委员会官方译法，并保持全表一致。
- 译法有争议时，先在对照表中标注「待术语确认」，建任务讨论后再定稿。
