# IQmol-for-Chinese 构建说明（中文版）

本文档说明如何从源码编译出**中文界面**的 IQmol 可执行程序，覆盖 Windows、Linux、macOS 三个平台，并附仓库拉取方式。

> 仓库地址：<https://github.com/stone-Glitch/IQmol-for-Chinese>
> 汉化成果：界面 1519 条翻译全部完成（`translations/zh_CN.ts`）、中文用户手册 34 页（`doc/IQmolUserGuide.pdf`）。

---

## 一、拉取仓库

IQmol3 依赖 9 个第三方库（以 Git 子模块形式存在），克隆时必须使用 `--recursive`：

```bash
git clone --recursive https://github.com/stone-Glitch/IQmol-for-Chinese.git
```

也可以使用仓库自带的一键脚本：

| 平台 | 脚本 | 说明 |
|---|---|---|
| Linux / macOS / Git Bash | `./scripts/clone_repo.sh` | 克隆或更新到当前目录 `IQmol-for-Chinese/` |
| Windows PowerShell | `.\scripts\clone_repo.ps1` | 克隆或更新到当前目录 |

### 子模块下载不动？用离线包（国内网络强烈建议先看这里）

子模块总共约 470 MB 源码，国内网络克隆经常卡住或直接
`Failed to connect to github.com:443`。**别硬扛，直接用离线包**：

1. 先只克隆主仓库（不带 `--recursive`）：

   ```bash
   git clone https://github.com/stone-Glitch/IQmol-for-Chinese.git
   ```

2. 下载离线包并解压到**仓库根目录**（包内顶层就是 `modules/`）：

   | 格式 | 大小 | 说明 |
   |---|---|---|
   | `IQmol-submodules.tar.gz` | 73 MB | 单文件，Windows 自带 `tar` 或 360压缩/7-Zip 可解压 |
   | `IQmol-submodules.zip` | 108 MB | 单层格式，任何解压软件直接右键解压 |

   两者内容完全相同（49,335 个文件）。存放位置见 README「子模块离线包」章节，
   或直接用 `scripts/extract_submodules.bat`（tar.gz 版）/ `scripts/merge_submodules.bat`（zip 分卷版）。

3. **解压后不要再执行 `git submodule update`**，否则会重新联网克隆覆盖掉刚解压的文件。

> ⚠️ 仓库路径请用**短英文路径**（如 `D:\iqmol`）。Windows 有 260 字符路径上限，
> 子模块源码目录层级很深，中文长路径会导致解压失败。

## 二、Windows 构建（产出 IQmol.exe）

### 0. 一键安装依赖（推荐，安装到 D 盘）

仓库提供了 `scripts/安装依赖.bat`，可自动将 MSYS2 安装到 **D 盘**（不占用 C 盘空间）并装好全部编译依赖：

1. 右键 `scripts/安装依赖.bat` → **以管理员身份运行**
2. 脚本会自动：下载 MSYS2 自解压归档 → 解压到 `D:\msys64` → 更新系统 → 安装 gcc/cmake/Qt5/Boost/OpenSSL/zlib/HDF5
3. 完成后双击 `D:\msys64\mingw64.exe` 进入 MINGW64 终端，直接跳到下方「3. 一键构建」

> 若不想装到 D 盘，可编辑脚本顶部 `MSYS2_ROOT` 变量改为其它盘符。

### 1. 手动安装 MSYS2（备选）

从 <https://www.msys2.org/> 下载并安装，打开 **「MSYS2 MINGW64」** 终端（注意：必须是 MINGW64，不是 MSYS 终端）。

### 2. 手动安装依赖（备选）

```bash
pacman -Syu   # 首次先更新系统，可能要求重启终端，之后重新进入 MINGW64
pacman -S --needed \
  mingw-w64-x86_64-gcc \
  mingw-w64-x86_64-cmake \
  mingw-w64-x86_64-make \
  mingw-w64-x86_64-qt5-base \
  mingw-w64-x86_64-qt5-tools \
  mingw-w64-x86_64-boost \
  mingw-w64-x86_64-openssl \
  mingw-w64-x86_64-zlib \
  mingw-w64-x86_64-hdf5
```

> 说明：`qt5-tools` 提供 `lrelease`（中文本地化）与 `windeployqt`（打包运行库），务必安装。

### 3. 一键构建

```bash
cd IQmol-for-Chinese
./scripts/build_windows.bat
```

脚本会自动完成：CMake 配置 → `mingw32-make` 编译 → 生成 `zh_CN.qm` → `windeployqt` 打包 Qt DLL → 复制 OpenBabel 数据文件。

### 4. 产物与分发

- 可执行文件：`build_win/IQmol.exe`
- 分发时需将 `IQmol.exe` 同目录的 **所有 DLL 与 `translations/`、`share/` 文件夹**一并打包（`windeployqt` 已自动铺好运行库）。

### 5. 手动构建（如不想用脚本）

```bash
mkdir build && cd build
cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release ..
mingw32-make -j
windeployqt --release IQmol.exe
```

## 三、Linux 构建

```bash
# 安装依赖（以 Ubuntu/Debian 为例）
sudo apt-get install build-essential cmake qtbase5-dev qt5-qmake \
  libqt5opengl5-dev libboost-all-dev libssl-dev zlib1g-dev \
  libopenbabel-dev libeigen3-dev libarchive-dev libyaml-cpp-dev \
  libssh2-1-dev libhdf5-dev libxml2-dev

cd IQmol-for-Chinese
./configure --release          # 生成 build/ 目录
cd build
make -j
```

产物：`build/IQmol`，中文 `.qm` 会随构建自动生成到可执行文件同级 `translations/`。

## 四、macOS 构建

```bash
brew install qt@5 boost openbabel libarchive yaml-cpp libssh2 hdf5 libxml2

cd IQmol-for-Chinese
./configure --release
cd build
make -j
```

产物：`build/bin/IQmol.app`（上游 CMake 已配置 macOS 打包）。

## 五、中文本地化说明

- **翻译文件**：`translations/zh_CN.ts`（1519 条，全部完成），构建时由 CMake 调用 `lrelease` 自动生成 `zh_CN.qm` 到可执行文件同级 `translations/` 目录。
- **更新翻译**（源码改动后）：运行 `./scripts/update_translations.sh`，脚本会自动修复 lupdate 因 `GLObject.h` 解析问题而误标的 vanished 条目，防止界面回退英文。
- **中文手册**：`doc/IQmolUserGuide.tex`，编译命令 `./scripts/build_docs.sh`（需安装 `texlive-xetex texlive-lang-chinese`）。

## 六、常见问题

| 问题 | 解决 |
|---|---|
| `cmake: command not found` | 未在 MINGW64 终端操作，或未安装 `mingw-w64-x86_64-cmake` |
| 找不到 Qt5 | 未安装 `mingw-w64-x86_64-qt5-base`，或未在 MINGW64 环境执行 |
| 界面仍是英文 | `qt5-tools` 未装导致 `lrelease` 缺失；装好后重跑构建 |
| 子模块为空/编译缺文件 | 优先用**离线包**解压（见上文）；网络好时可尝试 `git submodule update --init --recursive`，但国内大概率失败 |
| `git submodule update` 卡住/报 443 | 改用上文离线包方案；若目录已残留半截内容，先 `git submodule deinit -f --all` 再解压 |
| 解压报"路径太长"/无法创建 | 仓库移到短英文路径（如 `D:\iqmol`），或用 MSYS2 终端执行 `tar -xzf` |
| `windeployqt: command not found` | 安装 `mingw-w64-x86_64-qt5-tools` |
