制作视频

IQmol 中的部分动画可以录制为视频文件，供视频软件播放。在 OS X 上，IQmol 可以 利用系统内置的 QuickTime 支持生成 .mov 文件。在 Linux 和 Windows 上，IQmol 只会 保存单张图像文件，需要用第三方软件把它们合成为视频。 可以录制的动画有：

  • 振动频率
  • 反应路径（优化和 IRC）
  • 结构对称化
  • 加氢
  • 平移至中心

要录制动画，请点击工具栏上的"录制动画"按钮 。系统会提示你输入视频文件名 （OS X），或图像文件的基本名（Linux 和 Windows——单张图像文件会按顺序编号）。 之后工具栏按钮会开始闪烁，表示正在录制图像；由于要写盘，动画速度可能变慢。 所有动画会一直录制，直到再次点击"录制动画"按钮结束录制。在 OS X 上， 图像文件随后会被合成为 .mov 文件，根据视频长短，这一步可能有短暂的延迟。

录制时只录制自动更新的帧。如果录制期间手动旋转或以其他方式操作分子， 结果可能与你预期的不符。如果没有动画在播放，即使工具栏按钮在闪烁， 也不会录制任何帧。因此，例如在两个振动频率的动画之间暂停，最终视频里不会出现暂停。

录制振动频率和反应路径时，建议取消勾选配置器中出现的"循环"（Loop）复选框， 以免录制到多个循环周期。
