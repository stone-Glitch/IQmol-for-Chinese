运行 Q-Chem

IQmol 可以配置为在本地计算机或远程服务器上运行 Q-Chem 计算。为此， Q-Chem 必须已正确安装在实际执行计算的计算机上，并且还需要按下文所述配置一个服务器。

服务器配置

  1. 选择菜单 计算→编辑服务器 添加新服务器。此时会弹出一个对话框， 其中列出已配置的服务器，初始为空。
  2. 点击带 "+" 图标的"添加新服务器"按钮，打开服务器对话框以配置新服务器。 服务器指安装了你的 Q-Chem 副本的那台机器。

  3. 给服务器起个名字（仅用于标识当前的服务器配置，无须与实际机器名一致）， 并选择该机器是本地（即与 IQmol 运行在同一台机器上）还是远程。目前远程服务器必须是基于 Unix 的系统（即不支持 Windows 服务器）。
  4. 如果服务器上运行着 PBS 或 SGE 软件，请选择相应的"类型"选项； 否则选择"基本"（Basic）即可。
  5. 如有需要，可通过"配置"按钮进一步设置服务器。详见下文 服务器选项一节。
  6. 对于非 PBS 服务器，可以用内置的简单队列限制并发的 Q-Chem 任务数。 任务数上限由"任务上限"控件设定。若设为零，则禁用队列，可同时运行任意多个任务。 注意：此上限只对当前 IQmol 会话有效，不会统计其他用户或其他 IQmol 会话提交的任务。
  7. 对于远程服务器，还需提供机器地址和你的用户名。IQmol 通过 SSH 连接远程机器， 最方便的设置方式是使用授权密钥（设置方法参见 http://www.debian.org/devel/passwordlessssh）。这样 IQmol 可通过 SSH 代理连接， 无须再提示输入密码。如果无法使用 SSH 代理，还可以选择其他几种认证方式：
    • 公钥（Public Key）：需要输入 SSH 密语（如有）以解锁你的私钥文件。 密语只保存在内存中而不写入磁盘，因此每次运行 IQmol 都需要重新输入。
    • 密码保险库（Password Vault）：只需一个密码（保险库密钥）即可解锁所有已配置 服务器的密码。服务器密码在存盘前会用 64 位随机数加盐，并使用 AES 算法加密。 保险库密钥不会永久保存，每次运行 IQmol 都需要重新输入。
    • 密码提示（Password Prompt）：每次运行 IQmol 都需要输入服务器密码。 连接建立后，保存密码的内存会被覆写，以降低从核心转储中恢复出密码的风险。 除非你的公钥/私钥存放在非标准位置，否则无需再配置其他 SSH 选项。

对于远程服务器，建议在提交任务之前先测试服务器连接。如果你有多台装了 Q-Chem 的机器， 或有多个不同的账户配置，可以配置多个服务器。默认服务器是列表中的第一个， 可在服务器列表对话框中用箭头按钮调整顺序。

注意：对已有服务器的修改可能要重启 IQmol 后才生效。如果遇到问题（尤其是升级之后）， 建议删除该服务器并重新配置一个。

服务器选项

如果默认设置无法工作，可以在服务器对话框中点击"配置"按钮自定义行为。 这会打开服务器选项窗口：

"命令设置"定义了提交和控制 Q-Chem 进程时用到的几条命令。如果你的系统中 ps 等常用工具的路径非标准，或命令输出格式非标准，就可能需要修改这些设置。

"运行文件模板"是用于运行 Q-Chem 任务的脚本，可以配置为在输出文件中加入 主机名或开始时间等信息，或把临时文件复制到永久位置。如果你的 .cshrc（或等效文件）中 没有设置必要的 Q-Chem 环境变量，就需要在这里显式设置。

模板中的合法宏会在提交任务时替换为指定的值。宏以 ${...} 形式标识， 与环境变量不同（环境变量不带花括号）。可用的变量有：

  • ${JOB_ID}：PBS 服务器上为 PBS 任务编号，其他情况下为进程 ID。
  • ${JOB_NAME}：任务的基本名称，也是模型视图中显示的分子名。默认还会用它命名 输入输出文件，因此其中不应包含空格。

对于 PBS 服务器，还有以下附加变量。向 PBS 服务器提交任务时会提示用户为这些变量赋值：

  • ${QUEUE}：任务提交到的 PBS 队列名称。
  • ${WALLTIME}：任务的墙钟时间上限。
  • ${MEMORY}：任务的虚拟内存上限。
  • ${SCRATCH}：任务的文件空间上限。
  • ${NCPUS}：使用的 CPU 数量。注意需要并行版本的 Q-Chem，该选项才会生效。

提交计算

通过菜单 计算→Q-Chem 设置 来配置计算。弹出的对话框中已自动插入当前分子作为输入。 可以先用相应控件修改各项选项，然后选择目标服务器并提交任务。系统会提示你为工作目录命名， 如果是 PBS 服务器，还会提示设置资源限额。

请注意，虽然 Q-Chem 基于文件，但从 2.1 版起，IQmol 会用一个目录来整理一次计算的 各类文件。

任务监视器

任务成功提交后，可以通过任务监视器查看其进度。打开方式为菜单 计算→任务监视器。

任务监视器列出已提交的任务及其当前状态，刷新间隔由服务器选项对话框中的 "更新间隔"决定。在监视器中的条目上点击右键会弹出上下文菜单，可执行终止进程、 查看已完成计算的输出等操作。

任务成功完成后，输出会自动载入 IQmol。模型视图中会出现 图标，标示有新输出。
